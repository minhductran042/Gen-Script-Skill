# Tham khảo (tuỳ chọn)

Thư mục này **không phải luật**. Skill chỉ đọc file ở đây khi brief của lần làm đó ghi rõ ở mục "Tham khảo", ví dụ:

```
- Tham khảo: shared/tham-khao/phong-cach.md, shared/tham-khao/kho-hook.md
- Tham khảo: video mẫu người dùng mô tả ở dưới
- Tham khảo: không
```

Brief ghi "không", hoặc không nêu gì, thì skill **không đọc** thư mục này. Khi đó skill sáng tác chỉ dựa vào `shared/luat/`
và brief.

Khi đọc tham khảo, skill chỉ học cấu trúc / tinh thần, không chép thoại, cảnh hay chuỗi hành động.

| File | Nội dung |
|---|---|
| `phong-cach.md` | Chất riêng của team, khung beat, video mẫu đã bóc tách |
| `kho-hook.md` | Các dạng hook có mã |
| `giong-hai.md` | Giọng hài, cách nói của nhân vật |
| `mau/` | Thư viện bản phân tích video mẫu, mục lục ở `mau/INDEX.md` |

Thêm file tham khảo mới thì đặt ở đây và thêm một dòng vào bảng. Skill không tự ghi vào thư mục này, trừ một ngoại lệ:
`vid-phan-tich-mau` được ghi vào `mau/` **sau khi người dùng đồng ý lưu**.
